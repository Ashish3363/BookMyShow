# Frontend

React + TypeScript 7, built with Vite.

## Status

Folder structure only. Files are placeholders that say what they will hold.

## Layout

| Folder | Job |
|---|---|
| `src/bootstrap/` | App startup: providers, router, config |
| `src/shared/` | API client, common components and types |
| `src/features/` | One folder per feature: `api.ts`, `types.ts`, `hooks/`, `components/`, `pages/` |

## Run (after Step 2)

```bash
npm install
npm run dev
```
